EVIDENCIA 11. Aislamiento: el contenedor db NO es accesible desde el host
----------------------------------------------------------------
El contenedor ci_db no publica el puerto 5432 hacia la maquina anfitriona.
Solo el contenedor ci_web puede alcanzarlo, a traves de la red 'red-ci'.

$ nc -z -w 2 localhost 5432   (desde el host)
  -> conexion rechazada: el puerto 5432 no esta publicado (comportamiento esperado)

$ docker compose exec web python   (prueba de socket TCP hacia db:5432 desde el contenedor web)
  -> conexion TCP establecida con db:5432 desde el contenedor web
